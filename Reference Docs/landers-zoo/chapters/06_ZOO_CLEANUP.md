# Presentation to Miranda Lander

Alright, you've built all the features Miranda asked for! Now it's time for the big presentation.

But first... let's talk about your code. Is it currently one giant file that looks like a bowl of spaghetti? Time to clean that up before you show it to the boss!

Miranda doesn't care HOW you organize it, just that it's organized. Here are two solid strategies:

**Option A: Organize by Type** _(Group all habitat stuff together, all animal stuff together, etc.)_

**Option B: Organize by Function** _(Put all the data in one module, all the calculation functions in another, etc.)_

Once you've split things up, use ES6 `import` and `export` to connect everything. The goal? Your main `zoo.js` file should be nice and clean—just the display code. All the data and helper functions should be imported from other modules.

Think of it like organizing a zoo: you don't put penguins and tigers in the same enclosure, right? Same goes for your code! 🐧🐯
