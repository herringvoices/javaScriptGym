# Intro to Collections (Small Library Edition)

So far, you’ve stored values one box at a time—titles, page counts, flags. Real apps need to move **groups** of related values around together. That’s what **collections** are for.

In this standard, we’ll keep everything inside a tiny **book library**.

* **Objects** bundle related info about **one thing** (a single book) into key–value pages.
* **Arrays** keep an **ordered list** of things (all the books on a shelf).

You’ll build from loose primitives → book objects → arrays of titles → arrays of book objects, all in one growing script.

---

## One book = many separate variables

Start with a single book described by separate variables. No objects or arrays yet—just primitives.

```js
const book1Title = "The Way of Kings";
const book1Author = "Brandon Sanderson";
const book1Pages = 1007;
const book1IsPaperback = false;

console.log(book1Title);
console.log(book1Author);
console.log(book1Pages);
console.log(book1IsPaperback);
```


## Spot the pattern (and its pain)

Now that you have two books, notice how similar all these variables are: the names, the shapes, the log statements.

```js
console.log(book1Title, book2Title);
console.log(book1Pages, book2Pages);
```

## Checkpoint A · Primitive book data

By the end of this overview, your editor should look roughly like this (values can differ, but keep the structure and names):

```js
const book1Title = "The Way of Kings";
const book1Author = "Brandon Sanderson";
const book1Pages = 1007;
const book1IsPaperback = false;

const book2Title = "Words of Radiance";
const book2Author = "Brandon Sanderson";
const book2Pages = 1087;
const book2IsPaperback = false;

console.log(book1Title, book2Title);
console.log(book1Pages, book2Pages);
```

You’ll use these primitive variables to build proper book objects in the next chapter.
