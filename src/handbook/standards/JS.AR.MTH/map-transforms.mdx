<Callout type="tip" title="What does .join() do?">
`join(separator)` takes an **array of strings** and glues them into **one string**, putting the `separator` text between each item. For example, `names.join(", ")` turns `["Edgar", "Polly"]` into `"Edgar, Polly"`.
</Callout>

## The `map()` Method

`for...of` loops are useful and all, but our goal in this chapter is to learn tools that will almost totally replace them! `for...of` loops are like a kitchen knife: super flexible, you can do anything with it—but you have to do all the work by hand. The array methods we’re about to learn are like cookie cutters: each one only does one kind of job, but it does that job *really* well—so you give it the “shape” (your callback), run each item through, and it reliably hands you back a fresh batch of results.

`map()`, for example, takes an array, runs a callback on **every item**, and builds a **new array** from whatever the callback `return`s. The new array is the **same length** as the original.

Imagine you are writing thank you notes after a birthday party. You have a list of people's names and what they got you. In this scenario, you take on the role of the `map()` function, iterating over that list to produce one `thankYouCard` for every item in your list.

So if `thankYouList` looks like:

```js
const thankYouList = [
  { id: 1, name: "Tobias", gift: "McDonald's Gift Card"},
  { id: 2, name: "Deshawn", gift: "Coffee Maker"},
]
```

Then this:

```js
const thankYouCards = thankYouList.map((item) => `Dear ${item.name}, thank you for the ${item.gift}.`);
```

produces:

```js
["Dear Tobias, thank you for the McDonald's Gift Card.", "Dear Deshawn, thank you for the Coffee Maker."]
```

Once you have an array of strings, you can turn it into one string with a line break after each item using `join("\n")`:

```js
console.log(thankYouCards.join("\n"));
```
