# Array Methods → Filtering Arrays

## The `filter()` Method

`filter()` does exactly what it says on the tin: it lets you filter an array, and keep only the items that match a rule. It runs your callback on each item and:

- keeps it if the callback returns `true`
- skips it if the callback returns `false`

This callback is often called a **predicate**: it answers “yes or no?” for each item.

**Example:**

```js
const petOwners = students.filter((s) => s.pets > 0);
```

Now `petOwners` contains only student objects with at least one pet.

What about an example from real life? Maybe you've decided to surround yourself with only beautiful people?
```js
const myFriends = people.filter(p => !p.isUgly)
```
There! Now the `myFriends` array is only full of people for whom `isUgly` is `false` (note the `!`).

Maybe you love Starbursts, but only the pink ones?

```js
const pinkStarbursts = starbursts.filter((s) => s.color === "pink");
```
We could do this all day! The point is, `filter()` lets you pick through an array **item by item** and decide what should **_stay_** and what should **_go_** based on a condition.

### House sorting rules

At Boarblemish, students are sorted into houses based on their `nature`:

- `"brave"` → Dragonport
- `"smart"` → Crowbeak
- `"sneaky"` → Sidleup
- everything else → Heavysigh

You’ll use `filter()` to create a separate array for each house.
