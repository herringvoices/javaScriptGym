# Error Messages → `SyntaxError`

When you ran Mook's program, JavaScript did not make it to the shop heading.

It stopped before the program could really begin.

Before JavaScript can run your code, it first has to **parse** it. JavaScript has to read what you wrote and recognize it as valid JavaScript instructions.

The rules for writing valid JavaScript are called **syntax**.

A `SyntaxError` means JavaScript found code that does not follow those rules closely enough for it to understand the program.

Common causes include:

- a missing `)`, `]`, or `}`,
- a string with a missing quote,
- a missing comma between values or object properties,
- or another piece of malformed JavaScript.

A `SyntaxError` is JavaScript saying, roughly:

> **"I cannot understand this code well enough to run it."**

After your fix, the shop heading appears before JavaScript stops again.

That means you got farther.
