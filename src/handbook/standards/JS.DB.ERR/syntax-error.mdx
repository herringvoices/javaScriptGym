When you run this program, JavaScript does not make it to the shop heading. It stops before the program can really begin.

That is because JavaScript first has to **parse** your code: it has to read the characters you wrote and understand them as valid JavaScript instructions.

The rules for writing valid code are called **syntax**.

A `SyntaxError` means JavaScript reached code that does not follow those rules closely enough for it to understand the program.

Common causes include:

- a missing `)`, `]`, or `}`,
- a string with a missing quote,
- a missing comma between values or object properties,
- or another piece of malformed JavaScript.

<Callout type="tip" title="Read before you edit">
  <p className="m-0">The error usually includes a line and column near the place where JavaScript became unable to continue. That location is evidence. Start there instead of scanning the entire file at random.</p>
</Callout>
