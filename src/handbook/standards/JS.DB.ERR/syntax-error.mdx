# Error Messages → `SyntaxError`

## Welcome to Weird Mike's Pawn Shop

Before we start reading errors, you need something broken to debug.

Welcome to **Weird Mike's Pawn Shop**.

Nobody is completely sure whether "Weird Mike" describes Mike or the pawn shop. Either way, the inventory is unusual and the software needs work.

Mike had his nephew, **Mook**, put together a program for the shop.

It does not work.

The broken program is already waiting for you in `main.js`. Mook left several mistakes in it, and they are all there from the beginning.

**Do not start fixing things yet. Run the program first.**

JavaScript does not make it to the shop heading. It stops before the program can really begin.

That first error is where the debugging begins.

You will keep this same `main.js` through the Error Messages & Stack Traces project. Each time you understand and fix one problem, run the program again and see how much farther JavaScript gets.

Before JavaScript can run your code, it first has to **parse** it. JavaScript has to read what you wrote and recognize it as valid JavaScript instructions.

The rules for writing valid JavaScript are called **syntax**.

A `SyntaxError` means JavaScript found code that does not follow those rules closely enough for it to understand the program.

Common causes include:

- a missing `)`, `]`, or `}`,
- a string with a missing quote,
- a missing comma between values or object properties,
- or another piece of malformed JavaScript.

A `SyntaxError` is JavaScript saying, roughly:

> **"I cannot understand this code well enough to run it."**

After your fix, the shop heading appears before JavaScript stops again.

That means you got farther.
