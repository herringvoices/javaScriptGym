# Error Messages → `ReferenceError`

Run the program again after fixing the missing comma.

Good news: JavaScript made it far enough to print:

```text
WEIRD MIKE'S PAWN SHOP
```

Then it stopped with an error like:

```text
ReferenceError: managerName is not defined
```

That is different from the `SyntaxError`.

JavaScript understood the file well enough to start running it. This time it reached a name it could not find.

A **`ReferenceError`** usually means JavaScript was asked to use a variable or other name that does not exist in the current scope.

When you see one, pay attention to the exact name in the message.

Then ask:

- Is that name spelled correctly?
- Was it declared?
- Is there a similarly named variable nearby?

<Callout type="tip" title="Let the error name your search">
  <p className="m-0">
    If JavaScript says <code>managerName is not defined</code>, start by searching for <code>managerName</code>. Do not scan every function in the file. The error has already narrowed the problem down for you.
  </p>
</Callout>

A `ReferenceError` is JavaScript saying, roughly:

> **"I understand this code, but I do not know what that name refers to."**

The program now gets through two lines of output.

Then it finds a value, recognizes it perfectly well, and objects to what Mook tries to do with it.
