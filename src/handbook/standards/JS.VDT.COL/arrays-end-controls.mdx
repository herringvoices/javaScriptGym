# Data Types → Arrays (End Controls for Books)

You now have a <code>books</code> array of book objects. Real shelves change: you acquire new books, loan some out, and sometimes feature one at the very front.

Arrays give you built-in **methods** for these “end of the shelf” moves:

* <code>push</code> — add to the **end**
* <code>pop</code> — remove from the **end**
* <code>unshift</code> — add to the **start**
* <code>shift</code> — remove from the **start**

<Callout type="danger" title="What's a method?">
You'll learn more about methods in the next chapter.
- A method is an action you can perform on a piece of data.
- You use them by attaching them to the data with a <code>.</code>.
- You then tell the JavaScript engine to run that action by adding a <code>()</code> at the end.
- For example <code>myArray.pop()</code> would remove the last item from the end of <code>myArray</code>.

When you want to use a method that adds something to an array, you put the item you want to add in the parentheses: <code>myArray.push("hello!")</code> adds the string <code>"hello!"</code> to the end of <code>myArray</code>.
</Callout>

## 1) Push and pop on `books`

<code>push</code> places one or more items at the **end** of the array. <code>pop</code> removes the **last** item and returns it.

```js
console.log(books.length);
books.push({
  title: "Rhythm of War",
  author: "Brandon Sanderson",
  pages: 1232,
  isPaperback: true,
});
console.log(books.length);

const removedBook = books.pop();
console.log(removedBook.title);
```

## 2) Shift and unshift at the front

<code>shift</code> removes the **first** item and returns it. <code>unshift</code> adds items to the **start**.

```js
const firstBook = books.shift();
console.log(firstBook.title); // the book that left the very front

books.unshift(firstBook);
console.log(books[0].title);  // same title, now back at the front
```

## 3) Combine end controls to feature a book

You can mix these moves to reorder the shelf. For example, treat the last book as “now reading” and move it to the very front.

```js
const nowReading = books.pop();
books.unshift(nowReading);

console.log(books[0].title);
console.log(books.length);
```
