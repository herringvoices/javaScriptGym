# Data Types → Arrays (Book Titles & Counts)

Last time, you turned <code>book1Title</code> and friends into <code>book1</code> and <code>book2</code> objects. Now we’ll build **arrays of primitives** on top of those objects—ordered lists of titles and page counts.

---

## Before you start: make sure Checkpoint B is loaded

This chapter assumes your editor already has <code>book1</code> and <code>book2</code> objects, like this:

```js
const book1 = {
  title: "The Way of Kings",
  author: "Brandon Sanderson",
  pages: 1010,
  isPaperback: false,
  genre: "Fantasy",
};

const book2 = {
  title: "Words of Radiance",
  author: "Brandon Sanderson",
  pages: 1087,
  isPaperback: false,

```

If your editor does not have <code>book1</code> and <code>book2</code> objects like this, clear it and paste the **Checkpoint B** snippet from the Objects chapter.

## 1) A list of titles in one variable

Arrays are like **numbered shelves**: a single variable that holds many values **in order**.

```js
const titles = [book1.title, book2.title, "Oathbringer"];
console.log(titles);
```

## 2) Read by index (positions start at 0)

Each item in an array has a position called an **index**. Arrays are **zero-based**: the first item is at index <code>0</code>, the second at <code>1</code>, and so on.

```js
console.log(titles[0]);                 // first → "The Way of Kings"
console.log(titles[titles.length - 1]); // last  → "Oathbringer"
```

> <strong>Past the edge</strong><br />
> If an index doesn’t exist (too big or negative), the result is <code>undefined</code>. That’s JavaScript’s way of saying “no value lives here.”

## 3) Change a specific position

You can replace a single item by assigning to that index. The variable still points to the same array—only one slot inside changes.

```js
console.log(titles[1]);                  // "Words of Radiance"
titles[1] = "Words of Radiance (Revised Edition)";
console.log(titles[1]);                  // updated value
```

## Optional: page counts as a parallel list

If you’d like a second array to mirror <code>titles</code>, you can create a <code>pageCounts</code> array using numbers.

```js
const pageCounts = [book1.pages, book2.pages, 1248];
console.log(pageCounts);
```

This mirrors <code>titles</code> by index but uses numbers instead of strings.
