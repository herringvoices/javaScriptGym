# Data Types → Arrays of Objects (Book Records)

You’ve seen **book objects** (one binder per book) and **arrays of primitives** (titles in order). Now we’ll combine those ideas: an **array of book objects**—an ordered shelf where each slot holds a full book record.

---

## Before you start: make sure Checkpoint C is loaded

This chapter assumes you already have <code>book1</code> and <code>book2</code> objects, and probably a <code>titles</code> array. At minimum, you need:

```js
const book1 = {
  title: "The Way of Kings",
  author: "Brandon Sanderson",
  pages: 1010,
  isPaperback: false,
  genre: "Fantasy",
};

const book2 = {
  title: "Words of Radiance",
  author: "Brandon Sanderson",
  pages: 1087,
  isPaperback: false,
};
```

If your editor doesn’t have <code>book1</code> and <code>book2</code> objects like this, clear it and paste the **Checkpoint B or C** snippet from the previous chapters.

## 2) Assemble a `books` shelf (array of book objects)

Now combine <code>book1</code>, <code>book2</code>, and <code>book3</code> into a single ordered shelf.

```js
const books = [book1, book2, book3];
console.log(books.length);      // 3
console.log(books[0].title);    // first book’s title
console.log(books[2].author);   // third book’s author
```

## 3) Update one record via the array

You don’t have to reach for the original variable name (<code>book2</code>) to update a book—you can go through the array.

```js
console.log(books[1].pages); // original pages
books[1].pages = 1100;       // updated edition
console.log(books[1]);       // shows updated pages
```

## Checkpoint D · Three book objects on a shelf

By the end of this chapter, your editor should look roughly like this (values can vary slightly, but keep the structure):

```js
const book1 = {
  title: "The Way of Kings",
  author: "Brandon Sanderson",
  pages: 1010,
  isPaperback: false,
  genre: "Fantasy",
};

const book2 = {
  title: "Words of Radiance",
  author: "Brandon Sanderson",
  pages: 1100,
  isPaperback: false,
};

const book3 = {
  title: "Oathbringer",
  author: "Brandon Sanderson",
  pages: 1248,
  isPaperback: false,
};

const books = [book1, book2, book3];

console.log(books.length);
console.log(books[0].title);
console.log(books[2].author);
```

In the next chapter, you’ll pick up this same <code>books</code> array and learn **array methods** like <code>push</code>, <code>pop</code>, <code>shift</code>, and <code>unshift</code>—tools that let you add and remove books from either end of the shelf without juggling indexes by hand.
