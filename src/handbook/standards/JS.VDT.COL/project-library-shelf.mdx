# Mini Project → Library Shelf

*Last time we* grouped information with **objects**, kept order with **arrays**, combined both in **arrays of objects**, and used the end controls: `push`, `pop`, `unshift`, `shift`. *This time we’re* putting that all together—plus one new idea you’ll see everywhere in apps: **IDs**.

You’ll model a `library`:

* **Shape**: a single **object** named `library` with three properties
  • `name` → string
  • `librarian` → string
  • `books` → **array** (starts empty)
* **Each book**: an **object** with `id`, `title`, and `author`.
* **ID tracker**: a variable named `nextBookId` you’ll increment (add `1` to) as you add books.

---

<Callout type="note" title="Where do IDs usually come from?">
  <p className="m-0">
    In real apps, a database gives every record a unique <strong>id</strong> so you can refer to it precisely later (update one book, remove one book, etc.).
  </p>
  <p className="m-0">
    We’ll <strong>simulate</strong> that by keeping a counter called <code>nextBookId</code> in our code. When you create a book, you assign the current <code>nextBookId</code> as its <code>id</code>, then bump <code>nextBookId</code> up by 1 so the next book gets a fresh number.
  </p>
</Callout>

## 2) Add three books (arrays of objects + incremental IDs)

Each book is a tiny object with an `id`, a `title`, and an `author`. Put three of them into the `books` array **in order**, assigning an `id` from `nextBookId` and then incrementing the counter.

<HandbookChallenge
  title="Stock the shelf with unique IDs"
  hints={[
    <>Each new book should capture the current <code>nextBookId</code> before the counter changes.</>,
    <>After creating one book, increase <code>nextBookId</code> so the next object receives a different number.</>,
    <>Use <code>push()</code> to add each completed book object to <code>library.books</code>.</>,
  ]}
  solution={
    <pre className="m-0 whitespace-pre-wrap">{`const b1 = { id: nextBookId, title: "Sunset Drive", author: "Axton" };
nextBookId += 1;

const b2 = { id: nextBookId, title: "Neon Rain", author: "Riza" };
nextBookId += 1;

const b3 = { id: nextBookId, title: "Echoes & Honey", author: "Palmer" };
nextBookId += 1;

library.books.push(b1);
library.books.push(b2);
library.books.push(b3);

console.log(library.books);`}</pre>
  }
>
  <p className="m-0">
    Create three book objects named <code>b1</code>, <code>b2</code>, and <code>b3</code>. Each should have <code>id</code>, <code>title</code>, and <code>author</code>. Give each object the current <code>nextBookId</code>, increase the counter after each object, then push all three books into <code>library.books</code> and log the array.
  </p>
  <p className="m-0">
    You may choose your own titles and authors. The important result is three records with different IDs. <code>nextBookId += 1</code> is shorthand for <code>nextBookId = nextBookId + 1</code>.
  </p>
</HandbookChallenge>

<Callout type="note" title=".pop() returns the removed item">
  <p className="m-0">
    <em>const removed = library.books.pop()</em> breaks down like this:
  </p>
  <ul className="mt-2 mb-0 space-y-1">
    <li><code>const removed</code> — you name a new variable.</li>
    <li><code>=</code> — the assignment operator: “store what’s on the right into this variable.”</li>
    <li><code>library.books.pop()</code> — removes the <strong>last</strong> book and <strong>returns the book it removed</strong>.</li>
  </ul>
  <p className="m-0">JavaScript evaluates the right side first, then stores that returned book in <code>removed</code>. Now you can reuse it.</p>
</Callout>

<Callout type="tip" title="Curiosity check">

## 5) Practice: add → pop → unshift (with IDs, too)

Create your favorite book as an object **with an `id`**, add it to the end, take it off the end (pretend you “checked it out”), then put it at the beginning so it’s first in line.

<HandbookChallenge
  title="Move a favorite book to the front"
  hints={[
    <>Give the new book the current ID before increasing <code>nextBookId</code>.</>,
    <>The value returned by <code>pop()</code> is the object you need to move.</>,
    <>Use the method that adds an item to the start of an array to put that object first.</>,
  ]}
  solution={
    <pre className="m-0 whitespace-pre-wrap">{`const fave = {
  id: nextBookId,
  title: "Midnight Paper Planes",
  author: "Paper Planes Collective"
};
nextBookId += 1;

library.books.push(fave);
const nowReading = library.books.pop();
library.books.unshift(nowReading);

console.log(library.books[0].id, library.books[0].title);`}</pre>
  }
>
  <p className="m-0">
    Create a <code>fave</code> book with <code>id</code>, <code>title</code>, and <code>author</code>. Assign the current <code>nextBookId</code>, increase the counter, and push the book to the end. Then pop that book into <code>nowReading</code>, unshift it to the front, and log the first book’s <code>id</code> and <code>title</code>.
  </p>
</HandbookChallenge>

* This mirrors how real apps model data coming from a database: every record carries an <code>id</code> so you can target it confidently later.
