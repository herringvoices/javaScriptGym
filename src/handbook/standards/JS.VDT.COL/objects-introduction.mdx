# Data Types → Objects (Books as Binders)

In the overview, you described books with separate variables like <code>book1Title</code> and <code>book1Pages</code>. That works for a tiny library, but it scatters information about **one book** across many boxes.

**Objects** are our upgrade: they bundle related info together so it travels as a single unit—perfect for representing one book.

---

## Before you start: make sure Checkpoint A is loaded

This chapter assumes your editor already has separate variables for two books, like this:

```js
const book1Title = "The Way of Kings";
const book1Author = "Brandon Sanderson";
const book1Pages = 1007;
const book1IsPaperback = false;

const book2Title = "Words of Radiance";
const book2Author = "Brandon Sanderson";
const book2Pages = 1087;
const book2IsPaperback = false;
```

If your editor does not look roughly like this, clear it and paste the **Checkpoint A** snippet from the Collections overview chapter.

---

## 1) From scattered fields to one book object

Objects are like a **binder** for one book. Each **property** is a labeled page:

```js
const book1 = {
  title: book1Title,
  author: book1Author,
  pages: book1Pages,
  isPaperback: book1IsPaperback
};
```

## 3) Read and update fields on a book

With the objects in place, use **dot notation** to read and update properties.

```js
console.log(book1.title);  // "The Way of Kings"
console.log(book1.author); // "Brandon Sanderson"
```

You can also update fields or add new ones:

```js
book1.pages = 1010;         // updated edition
book1.genre = "Fantasy";   // new field
```

Brandon Sanderson
1010`}</pre>
  }
  solution={
    <pre className="m-0 whitespace-pre-wrap">{`console.log(book1.title);

  }
>
  <p className="m-0">
    Log <code>book1.title</code> and <code>book1.author</code>. Change <code>book1.pages</code> to <code>1010</code> and log the new value. Then add a <code>genre</code> property with the value <code>"Fantasy"</code> and log the whole object.
  </p>
</HandbookChallenge>

> <strong>Const vs. mutation</strong><br />
> <code>const book1 = {'{'}{'}'}</code> locks the variable-to-object link, not the pages inside. You can still update or add properties; you just can’t reassign <code>book1</code> to a completely different object.

## Checkpoint B · Two book objects

By the end of this chapter, your editor should look roughly like this (details like <code>pages</code> or <code>genre</code> may vary, but keep the structure):

```js
const book1 = {
  title: "The Way of Kings",
  author: "Brandon Sanderson",
  pages: 1010,
  isPaperback: false,
  genre: "Fantasy",
};

const book2 = {
  title: "Words of Radiance",
  author: "Brandon Sanderson",
  pages: 1087,
  isPaperback: false,
};

console.log(book1.title, "by", book1.author);
console.log(book2.title, "by", book2.author);
```

You’ll use these <code>book1</code> and <code>book2</code> objects to build arrays of titles in the next chapter.
