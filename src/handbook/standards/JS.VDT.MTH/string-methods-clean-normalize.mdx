# Data Types → String Methods

*Last time we* worked with **arrays** and their end-controls (`push`, `pop`, `unshift`, `shift`). Those are **methods**—functions attached to a value. *This time we’re* giving **strings** their own little toolbox. Arrays aren’t the only data type with useful methods and properties.

Two quick reminders before we start:

* A **property** is information **on** a value (no parentheses). Example: <code>.length</code>.
* A **method** is a function **attached to** a value (uses parentheses). Example: <code>text.trim()</code>. Most string methods **return a new string**—store it if you want to keep the change.

---

## 1) `.length` — how many characters?

`.length` tells you the number of characters in a string. It’s a **property**, so there are **no parentheses**. You’ll use it any time you want to check “how long is this text?”.

**Example:**

```js
const username = "Nick";

console.log(username.length);           // 4
```

---

## 2) `.trim()` — remove extra spaces at the ends

User input often comes with leading or trailing spaces. `.trim()` cleans both ends at once. It does **not** change the original string; it returns a **new** one without the outer spaces.

**Example:**

```js
const rawName = "   Nick  "; //Notice the extra spaces on the outside?
const cleanName = rawName.trim();

console.log(rawName);   // "   Nick  " (original, still messy)
console.log(cleanName); // "Nick" (new, trimmed string)
```

---

## 3) `.toLowerCase()` / `.toUpperCase()` — normalize case

When you compare or store text, it helps to normalize the casing. `.toLowerCase()` returns a new, all-lowercase version and `.toUpperCase()` returns an all-uppercase version. These are perfect for case-insensitive comparisons like emails, usernames, or search, or for formatting a label.

**Example:**

```js
const emailInput = "  NICK@example.com ";
const normalizedEmail = emailInput.trim().toLowerCase();
const shoutingEmail = normalizedEmail.toUpperCase();

console.log(normalizedEmail); // "nick@example.com" (good for comparisons)
console.log(shoutingEmail);   // "NICK@EXAMPLE.COM" (formatted version)
```

---

## 4) `.split(delimiter)` — cut a string into parts (array out)

`.split()` cuts one big string into pieces wherever it finds a marker you choose. That marker is the **delimiter**—just “the thing in between” your pieces, like a space between first and last name, or a comma between items in a list. The original string stays the same; the new array holds each chunk.

**Example:**

```js
const tags = "plants, bots, rocks";
const parts = tags.split(", "); // split wherever you see comma+space

console.log(parts);    // ["plants", "bots", "rocks"]
console.log(parts[0]); // "plants"
console.log(parts[1]); // "bots"
```

---

## 5) `.replace(searchValue, replaceValue)` — swap the first match

`.replace()` finds the **first** occurrence of a substring and swaps it. It returns a **new string** with that change; the original stays as it was.

**Example:**

```js
const phone = "615-555-1234";
const tidy = phone.replace("-", " ");

console.log(phone); // "615-555-1234" (unchanged)
console.log(tidy);  // "615 555-1234" (first dash replaced)
```

---

> **What does a method “give back”?**
> Just like <code>const removed = songs.pop()</code> returns the item it removed, most string methods return a **new string**. They don’t change the original; they hand you a transformed copy. Store it if you need it.

## Technical Vocabulary

| Term | Quick meaning | Tiny example |
| ---- | ------------- | ------------ |
| **Property** | A fact **on** a value (no parentheses). | <code>username.length</code> → how many characters are in the string. |
| **Method** | An action **attached to** a value (has <code>()</code>). | <code>username.trim()</code> → returns a new string with the edges cleaned. |
| <code>.length</code> | String (or array) property for the total count. | <code>"hello".length</code> is <code>5</code>. |
| <code>.trim()</code> | String method that removes spaces at the start and end. | <code>"  hi ".trim()</code> → <code>"hi"</code>. |
| <code>.toLowerCase()</code> | String method that returns an all-lowercase copy. | <code>"Hi".toLowerCase()</code> → <code>"hi"</code>. |
| <code>.split(delimiter)</code> | String method that returns an **array** of pieces. | <code>"a,b,c".split(",")</code> → <code>["a","b","c"]</code>. |
| <code>.replace(search, replace)</code> | String method that swaps the **first** match. | <code>"615-555".replace("-", " ")</code> → <code>"615 555"</code>. |
| **Normalize** (text) | Put text into a consistent format before comparing or storing. | Trim spaces and lowercase an email before saving it. |
