## Trace the code, not the report

Here is a different program:

```js
const label = createShippingLabel(order);

console.log("======SHIPPING======");
console.log(`Postage: $${calculatePostage(order)}`);
```

Even though `calculatePostage()` appears inside a template literal and a `console.log()`, JavaScript still has to call it before it can finish constructing the string.

The important cross-module interactions are therefore:

1. call `createShippingLabel()`,
2. receive the label,
3. call `calculatePostage()`,
4. receive the postage total.

The matching diagram could be:

```mermaid
sequenceDiagram
  participant Main as main.js
  participant Shipping as shipping.js
  Main->>Shipping: createShippingLabel(order)
  Shipping-->>Main: shipping label
  Main->>Shipping: calculatePostage(order)
  Shipping-->>Main: $8.50
```
