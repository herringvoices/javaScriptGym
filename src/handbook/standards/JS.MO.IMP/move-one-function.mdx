# Modules → Move One Function

The data has a home.

Now look at what remains in `main.js`.

Three functions perform reusable Census operations:

- `countConfirmed()`
- `findCryptidByName()`
- `totalSightingsInRegion()`

Eventually they can live together.

Do not move all three yet.

First, move one and prove that you can reconnect it correctly.

## Create `census.js`

Create:

```text
/census.js
```

Move only `countConfirmed()` from `main.js` into that file.

Then export it:

```js
export { countConfirmed };
```

Back in `main.js`, import it:

```js
import { countConfirmed } from "./census.js";
```

Your imports should now be together at the top of the file:

```js
import { cryptids } from "./data.js";
import { countConfirmed } from "./census.js";
```

Run the program.

The confirmed count should still be `6`.

## The architecture changed too

You just added another import relationship.

That means the dependency graph is now out of date.

This is why diagrams are maintained with the code. They describe the current project, not the project you had twenty minutes ago.

## A useful habit

Code first.

Run it.

Then update the diagram.

That order lets the working code tell you what the architecture actually is.
