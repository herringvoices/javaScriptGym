# textContent · Put Plain Text on the Page

The app has a selected mount point, but the user still sees nothing.

> We found the app container. Now we need to prove we can change what appears inside it.

## Concepts

- `textContent` changes the plain text inside an element.
- `textContent` does not create HTML.
- Assignment updates the DOM immediately.

## Code

```js
app.textContent = "Potion Shelf loading...";
```

## Keep vs Trash

Keep:

```js
app.textContent = "Potion Shelf ready.";
```

Trash it on the next page when switching to `innerHTML`.

## Technical Vocabulary

| Term | Meaning |
| --- | --- |
| `textContent` | A property that sets or reads plain text inside an element |
| property | A value stored on an object |
| assignment | Using `=` to store or replace a value |
