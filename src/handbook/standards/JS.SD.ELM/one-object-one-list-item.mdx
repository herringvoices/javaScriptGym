# One Object → One List Item

The app has real potion data now, but nothing from that data appears on the page.

> We need to turn one potion object into one piece of HTML.

## Concepts

- Access object properties with dot notation.
- Template literals insert data into strings.
- One object can become one HTML string.
- `innerHTML` can render that string into the list.

## Code

```js
const firstPotion = potions[0];

potionList.innerHTML = `
  <li>${firstPotion.name}</li>
`;
```

## Technical Vocabulary

| Term | Meaning |
| --- | --- |
| dot notation | Reading a property with `object.property` |
| template literal | A backtick string that can insert values with `${}` |
| interpolation | Inserting a value into a string |
| index | A number used to access an array item |
