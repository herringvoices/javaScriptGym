# DOM Basics · The Page as Objects

HTML creates the starting page. The browser turns that HTML into the DOM. JavaScript can select parts of the DOM and change them.

The page currently has this mount point:

```html
<div id="app"></div>
```

But nothing visible appears inside it unless JavaScript puts something there.

> Our HTML has a place for the app, but JavaScript has not found it yet.

## Concepts

- The DOM is the browser's live model of the page.
- `document` represents the page.
- Elements are objects.
- To change an element, select it first.

## Code

```js
const app = document.querySelector("#app");
console.dir(app);
```

## Keep vs Trash

Keep:

```js
const app = document.querySelector("#app");
```

Trash:

```js
console.dir(app);
```

## Technical Vocabulary

| Term | Meaning |
| --- | --- |
| DOM | The browser's live object model of the page |
| `document` | The JavaScript object that represents the page |
| element | A DOM object created from an HTML tag |
| selector | A string used to find an element |
| mount point | The container where the app renders |
