# PotionItem · A Function That Returns HTML

Rendering one potion directly works, but the app will need to render many potions.

> If we write the `<li>` by hand every time, we repeat ourselves.

## Concepts

- A component is a function that returns an HTML string.
- Components are capitalized by convention.
- A parameter lets the function work with any potion.
- `return` sends the HTML string back.

## Code

```js
const PotionItem = (potion) => {
  return `<li>${potion.name}</li>`;
};

potionList.innerHTML = PotionItem(potions[0]);
```

## Keep vs Trash

Keep:

```js
const PotionItem = (potion) => {
  return `<li>${potion.name}</li>`;
};
```

Trash direct one-off `<li>` rendering outside the component.

## Technical Vocabulary

| Term | Meaning |
| --- | --- |
| component | A function that returns an HTML string |
| parameter | A named input a function can use |
| argument | A value passed into a function |
| `return` | Sends a value out of a function |
