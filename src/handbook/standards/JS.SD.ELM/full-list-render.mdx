# Full List Render

You’ve already rendered **one** item into the DOM.

Now we’re going to render **all** of them.

The main idea is simple:

1. Turn every item in an array into an HTML string
2. Combine those strings into **one** big string
3. Set `innerHTML` **once**

---

## `map()` turns “array of data” into “array of strings”

`map()` runs once for each item in an array, and it builds a new array out of whatever your function returns.

### Example

```js
const pets = ["Dexter", "Miso", "Waffles"];

const PetTag = (name) => `<div class="tag">${name}</div>`;

const petTagsArray = pets.map(PetTag);

// petTagsArray is now:
// [
//   '<div class="tag">Dexter</div>',
//   '<div class="tag">Miso</div>',
//   '<div class="tag">Waffles</div>'
// ]
```

That’s useful… but `innerHTML` doesn’t want an array.

It wants **one string**.

---

## `join("")` turns “array of strings” into “one big string”

`join("")` smushes an array of strings together into a single string.

### Example

```js
const pets = ["Dexter", "Miso", "Waffles"];
const PetTag = (name) => `<div class="tag">${name}</div>`;

const bigString = pets.map(PetTag).join("");

// bigString is now:
// '<div class="tag">Dexter</div><div class="tag">Miso</div><div class="tag">Waffles</div>'
```

Notice we use `join("")` (an empty string) so we don’t accidentally insert commas between items.

---

## Putting it together with `innerHTML`

Once you’ve got one big string, you can render it in one shot:

### Example

```js
const pets = ["Dexter", "Miso", "Waffles"];
const PetTag = (name) => `<li>${name}</li>`;

const listEl = document.querySelector("#pet-list");
listEl.innerHTML = pets.map(PetTag).join("");
```

---

<Callout type="tip" title="A Lack of map() Arguments">
When you see this:

```js
pets.map(PetTag)
```

it can feel weird at first, because it looks like we forgot the argument.

But `map()` is the one that supplies the argument.

`map()` goes through the array and calls your function once per item. Each time, it hands your function the current item automatically.

So these two lines do the same thing:

```js
pets.map(PetTag)
pets.map((p) => PetTag(p))
```

We use the shorter version when we can because it’s easier to read.
</Callout>

## Recap

You can now:

* Select DOM elements using `getElementById` and `querySelector`
* Update plain text UI using `textContent`
* Render HTML UI using `innerHTML`
* Turn one object into one HTML string using `ProfileItem(profile)`
* Render an entire array using `map` + `join("")`

## Technical vocabulary

| Term            | Meaning                                                 |
| --------------- | ------------------------------------------------------- |
| **DOM**         | The browser’s live model of the page (a tree of nodes)  |
| **Element**     | A DOM node that corresponds to an HTML tag              |
| **Selector**    | A string used to find elements (like `#app` or `.tab`)  |
| **Mount point** | The container your UI renders into (often `#app`)       |
| **Render**      | Update the DOM so the UI matches the current data       |
| **textContent** | Sets plain text inside an element (no HTML parsing)     |
| **innerHTML**   | Sets HTML inside an element (creates real DOM nodes)    |
| **Module**      | A JS file that can import/export code (`type="module"`) |
| **Export**      | Make a function/variable available to other files       |
| **Import**      | Bring an exported function/variable into your file      |
