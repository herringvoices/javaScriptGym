# innerHTML · Render the App Shell

Plain text proves JavaScript can update the page, but an app needs structure: headings, sections, containers, and lists.

> A real app needs HTML, not just a sentence.

## Concepts

- `innerHTML` treats a string as HTML markup.
- The browser turns that markup into DOM nodes.
- A shell is the stable structure the app renders into.

## Code

```js
app.innerHTML = `
  <header>
    <h1>Potion Shelf</h1>
    <p>A tiny catalog for a magical shop.</p>
  </header>

  <main>
    <section>
      <h2>Available Potions</h2>
      <ul id="potion-list"></ul>
    </section>
  </main>
`;
```

## Technical Vocabulary

| Term | Meaning |
| --- | --- |
| `innerHTML` | A property that sets or reads HTML inside an element |
| markup | HTML written as text |
| app shell | The basic page structure the app renders into |
| container | An element that holds other elements |
