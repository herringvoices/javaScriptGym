# join("") · One Big String for innerHTML

`map()` gives us an array of strings, but `innerHTML` needs one string.

> The DOM does not need an array of list items. It needs one HTML string.

## Concepts

- `join("")` combines an array of strings.
- `join("")` avoids commas between list items.
- Set `innerHTML` once after the final string is ready.

## Code

```js
const potionHTML = potions.map(PotionItem).join("");

potionList.innerHTML = potionHTML;
```
