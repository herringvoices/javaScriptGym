# Full List Render · map() Turns Data Into HTML

`PotionItem(potions[0])` proves the component works, but the shelf needs every potion.

> We have an array of potion objects, but the DOM needs one HTML string.

## Concepts

- `map()` runs once per item.
- `map()` can call `PotionItem` for each potion.
- The result is an array of HTML strings.
- The array is not ready for `innerHTML` yet.

## Code

```js
const potionHTMLArray = potions.map(PotionItem);
console.log(potionHTMLArray);
```

## Technical Vocabulary

| Term | Meaning |
| --- | --- |
| `map()` | Creates a new array by transforming each item |
| callback | A function passed into another function |
| transform | Change one kind of value into another kind of value |
