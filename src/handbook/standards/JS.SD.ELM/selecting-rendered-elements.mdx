# Selecting Rendered Elements · Find the List

The app shell includes:

```html
<ul id="potion-list"></ul>
```

But JavaScript cannot select that list until after the shell has been rendered.

> You cannot select an element that does not exist yet.

## Concepts

- DOM updates happen in order.
- If `innerHTML` creates an element, select that element after setting `innerHTML`.
- `querySelector()` returns `null` when nothing matches.

## Code

```js
const potionList = document.querySelector("#potion-list");
console.dir(potionList);
```

## Keep vs Trash

Keep:

```js
const potionList = document.querySelector("#potion-list");
```

Trash:

```js
console.dir(potionList);
```
