# Methods: Tools for Your Data Types

So far, you’ve built:

- **Boxes** (variables) that hold values
- **Binders** (objects) that group labeled fields
- **Playlists** (arrays) that keep items in order

Every data type comes with its own **toolbelt**: built-in facts and actions you can use to inspect or transform values without writing everything from scratch.

<Callout type="note">

- A **property** is a fact you can read. It does **not** use parentheses.
  - Example: <code>name.length</code> → "how many characters are in this string"
- A **method** is an action you perform. It **does** use parentheses.
  - Example: <code>name.toUpperCase()</code> → "return a new, uppercased string"

You don’t have to memorize every method. The goal here is to recognize that **each type has its own tools**, and to get comfortable reading and using a few of them.
</Callout>

---

## 1) Properties vs Methods

A few examples:

```js
let name = "Ada Lovelace";
let books = ["The Way of Kings", "Words of Radiance"];

name.length;         // property → how many characters
name.toUpperCase();  // method → returns "ADA LOVELACE"

books.length;        // property → how many items
books.push("Oathbringer"); // method → add one item to the end
```

Rule of thumb:

* **No `()`** → property → “just a fact”
* **Has `()`** → method → “do something / return something”

## 2) Different types, different toolbelts

Each data type has tools that make sense for the kind of data it holds:

* **Strings** (text)

  * Tools to **clean** and **normalize** text:

    * remove extra spaces, change case, split into pieces, replace parts of a message.
* **Numbers**

  * Tools to **parse** and **format**:

    * turn `"2.99"` into a usable number, check if something is really a number, format decimals for display.
* **Objects**

  * Tools to **peek at structure**:

    * list all keys, list all values, walk through key/value pairs.
* **Arrays**

  * Tools to **manage lists**:

    * add or remove items from the ends, count how many items you have, later even search or sort.

You’ll see concrete examples of these in the next few chapters—one type at a time.
