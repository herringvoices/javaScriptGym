# Iteration → Repeating Actions on Purpose

Welcome! In this chapter you’ll meet another big idea in JavaScript: **iteration** — the way your program repeats actions on purpose.

Imagine a machine that does the same thing over and over again.
If you set it up to make tacos, it will make taco after taco until you tell it to stop.
If you tell it to email your grandmother, it will send her the same email again and again and again.
That’s what iteration is in code: you give the computer a small script to run, and it repeats that script until your rule says “enough.”

---

## 1) The machine’s three settings: Start, Stop, Step

Our repeating machine always needs three settings before it can do anything useful:

* **Start** — how things look before repetition begins
  (for example, a counter at `0`, or the first hero in a list).
* **Stop** — the rule that must stay true for the machine to keep running
  (for example, “we haven’t hit 10 tacos yet” or “we still have heroes left in the array”).
* **Step** — what happens at the end of each loop
  (for example, “add `1` to a counter” or “move to the next name in the list”).

You can imagine turning a few dials on the front of the machine:

* Should we start counting from 0 or from 1?
* Do we stop after 3 emails, or after 100?
* Do we add 1 each time, or skip every other item?

Every useful loop has:

* a **Start** (how things look before repetition begins),
* a **Stop** rule (the condition that must stay true to keep repeating),
* and a **Step** (how you change things after each run so you eventually hit the stop rule).

In the next chapters, you’ll see how JavaScript’s `for` and `for…of` loops let you program these three settings directly, so the computer can be the repeating machine for you.

## Practice · Spot repetition before loops

Before we let JavaScript act as the repeating machine for us, you’ll do things the “manual” way once. For now, **you** are going to be the machine: you’ll repeat the same pattern by hand and feel how repetitive it is.

The examples below assume you already have a `heroes` array in your file with several hero objects. You’ll work with that data directly.

* You **stopped** when you ran out of heroes.
* You **stepped** forward by changing the index or picking the next hero yourself.
